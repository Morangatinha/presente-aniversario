- pieces/piece_01.jpg ... piece_30.jpg

PUBLICAÇÃO
1. Publique worker.js no Cloudflare Workers.
2. Copie a URL HTTPS do Worker.
3. O index.html já está configurado com a URL do seu Cloudflare Worker.
4. Publique index.html e a pasta pieces no GitHub Pages.

DATAS
01/10 = peça 1
02/10 = peça 2
...
29/10 = peça 29
30/10 = peça 30 + mensagem final

PROTEÇÃO
A data é calculada pelo Worker no fuso America/Sao_Paulo, então alterar o relógio do computador não libera peças.
A montagem é salva no navegador e as peças podem ser arrastadas para seus lugares.
IMPORTANTE: as imagens das peças ainda estão públicas no GitHub Pages. Um usuário tecnicamente avançado pode descobrir URLs dos arquivos antes da data. Para proteção contra isso, o próximo passo é colocar as peças em armazenamento privado (Cloudflare R2) e fazer o Worker entregar somente as peças permitidas.
